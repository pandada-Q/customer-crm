# 01: 共享底座：schema + 单一口令 + 应用骨架 + 留痕撤销底层

**要交付什么**：搭建「静态前端 + 轻量后端 + 数据库」最小应用骨架。定义统一联系人 schema（姓名/公司/手机/座机/邮箱/城市/备注 + 可空附加列：合作状态/录入人/标签 + 「来源」列，D1/D10），建联系人、待确认条目、修改留痕、待办四类数据表；单一口令鉴权（不分只读/操作口令，D18①）；前端五个占位路由（总表/待确认区/意向筛选/待办/上传）；后端统一留痕写底层（记录操作人/时间/字段/旧值→新值，D18②）与撤销原语。本张不做业务功能，只保证后续切片有干净的骨架与 schema 契约。

**阻塞（Blocked by）**：无（可立即开工）

**状态**：待开发

**验收标准**：
- [ ] 输入正确口令可访问应用，错误口令被拒绝（D18①）
- [ ] 数据库含联系人（统一 schema + 附加列 + 来源列）、待确认条目（type 区分 冲突/疑似重复/低置信）、留痕、待办四类表；schema 与 D1 一致
- [ ] 任一业务写操作走统一留痕：记录操作人/时间/字段/旧值→新值，支持按条目撤销（D18②）
- [ ] 前端五个路由可访问（内容可为占位页），静态前端 + 后端 + DB 三层本地可联调跑通（D15 架构）
- [ ] 应用内无自由增删改联系人入口（仅留好拍板/确认/勾选/上传的操作通道，D18③ 边界由后续票落地）
