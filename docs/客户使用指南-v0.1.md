# 客户使用指南（v0.1 培训版）

> 面向不使用技术文档的同事/客户。读完这份，你就能自己把客户资料导进去、把该拍板的事拍掉。
> 配套演示：用仓库 `input/` 里的样例文件（都是虚构数据）练一遍即可上手。

---

## 一、这个版本交付了什么？

一句话：**你把自己手里的客户资料（Excel 名单、CSV、甚至微信里随手发的联系人文字）丢进来，它帮你整理成一份整齐的客户档案，并且告诉你有谁值得跟进、有什么事情还没办。**

它能做四件事：

| 它帮你做什么 | 举个例子 |
| --- | --- |
| **1. 自动整理入库** | 上传老系统导出的名单 + 市场部的 Excel + 王总微信发来的一段文字，系统自动合并成一份不重复的客户表 |
| **2. 拿不准的问你** | 同一个客户在两份名单里手机号不一样？它不自己猜，而是放进"待确认区"请你拍板 |
| **3. 帮你盯意向和待办** | "展会认识的李莉"被自动标为待跟进；"张伟说下周约饭记得提醒"被抽成一条待办 |
| **4. 随时问它** | 右下角有个 AI 小助手，可以问"佛山有哪些客户？"“帮我推荐几个合作状态有效的客户”，它只回答**系统里已有的数据** |

## 二、你该怎么用（5 分钟上手）

### 第 1 步：登录
浏览器打开系统地址，输入访问口令（找管理员要，别外传）。

### 第 2 步：认识四个页面
顶部导航从左到右：

| 页面 | 干什么用 |
| --- | --- |
| **客户总表** | 所有客户档案。右上角可以搜索（名字/公司/手机/城市）、按城市/标签/合作状态筛选 |
| **待确认区** | ⭐ 系统"拿不准、需要你判断"的地方，**建议每天先看这里**，把它清零 |
| **意向客户** | 有意向、待跟进的客户清单，点"跟进"登记是谁在跟 |
| **待办** | 从聊天/材料里抽出来的待办事项（如约饭提醒），点按钮标记完成/搁置 |

右上角是"退出"（数据都保存在本机，退出不影响）。

### 第 3 步：上传你的资料
在**客户总表**页面右侧的"上传"区：

1. 把文件拖进来（或点选择文件）——支持 **CSV、Excel 导出的 CSV、JSON、.txt 文本**，也支持**直接粘贴微信聊天文字**；可以一次拖多个
2. 点"上传处理"，等进度条走完
3. 下方"上传处理记录"会告诉你每个文件处理的结果：新增了几个、合并了几个、有几个进了待确认区

> 小提示：一份"市场部名单"可能同时有正本和副本，传两份也没关系，系统会认出是同一批人、不重复入库。

### 第 4 步：处理"待确认区"
待确认区有三种卡片，都是**系统拿不准、需要你拍板**的：

- **⚠ 字段冲突**：同一个客户在不同来源里写了不一样的值（比如手机号两个版本）。卡片会标出"值A 来自哪个文件、值B 来自哪个文件"，点"采纳推荐"或"用A值/用B值"即可。
- **💡 合作意向初判**：系统根据"展会认识/可跟进/合作过"这类信号判断客户有意向。属实就点"确认意向"，不属实点"驳回"。
- **❓ AI 低置信**：系统对这条数据没把握（比如手机号看起来不对、电话没找到）。点"修改/补全"把正确信息填上，或"确认剔除"删掉。

> 原则：**待确认区处理完 = 数据就绪**。这里不处理，不会自动消失，但也不会影响总表里的其他数据。

### 第 5 步：使用意向客户与待办
- **意向客户页**：每条客户后面有「跟进」和「移除」两个按钮——跟进时填**跟进人**（谁负责跟），系统记下时间；移除表示不列入意向。
- **待办页**：每条待办可按状态筛选（待处理/完成/搁置/已移除）。做完的事点"完成"，暂时不做的点"搁置"，不想要的点"移除"（都能恢复，不会真删）。

### 第 6 步：问 AI 小助手（可选）
右下角圆形 **AI** 按钮 → 对话框打开会先看到引导语。可以直接问：

- "佛山有哪些客户？"
- "有几个意向客户，分别在哪些城市？"
- "推荐几个合作状态为有效的客户"
- "我有哪些待办？"

它只会从**系统里已有的数据**里找答案，查不到就明说，不会编造，也不会上网搜。

## 三、你处理数据时，系统替你做了哪些重要决定？

这些规则是自动发生的，**你不需要操作**，但了解它们能让你放心：

| 系统自动做的事 | 说明 |
| --- | --- |
| **同一人去重合并** | 同一客户在多个文件出现，合并成一条，来源都保留。两份相同的名单不会导致数据翻倍 |
| **垃圾字段搬家/清理** | 手机号误填到城市列会被搬回手机列；纯数字的"城市"会被清空而不是当城市存 |
| **标签去重** | "客户/客户"这种重复标签自动去成一个 |
| **合作状态归一** | 口语描述自动归成三档：**有效**（合作过/长期合作）、**待定**（展会认识/可跟进/有意向）、**暂停** |
| **公司名断句还原** | 如果名单里公司名被逗号断成两截（如"深圳市创新,科技有限公司"），系统会按各列内容自动拼回完整公司名 |
| **可疑手机号不静默处理** | 手机号少一位（10 位）会**保留原号**并提示"位数不足"，请你补全——而不是悄悄丢掉再笼统报"缺电话" |
| **拿不准的绝不猜** | 所有不能确定的事都进**待确认区**交给你，宁可多问一次，不静默写错 |

为什么敢让它自动做这些？因为**每一项都有规则可查、有留痕可追溯**，你随时可以撤销任何一次修改。

## 四、这次没有做什么（重要，管理预期）

- **没有"账号"概念**：系统只有一个访问口令，谁操作都记成同一个操作人——多人使用时建议专人管理或等 v0.2 的账号权限版
- **没有回收站**：清空/删除操作不可恢复（系统内"移除"类操作可恢复，但管理员"清空数据"不可恢复）
- **AI 只读、不联网**：小助手只能查系统内数据并给建议，不能直接帮你改资料；也不会去网上搜这家公司
- **待办没有截止日期**：只能记事项与状态，不能设"下周三前完成"（v0.3 会加）
- **不支持 Excel(.xlsx) 原文件**：请先另存为 CSV 或用文本粘贴（v0.5 会直接支持）
- **不支持多人同时在线协作**：本质是单机/内网小工具

## 附：数据与隐私承诺

- 所有客户数据**只存在你自己电脑/内网的 `data/db.json` 文件**里，不上传任何云数据库
- 只有两种情况下会调用 DeepSeek 大模型：① 上传**纯文字**资料需要抽取时；② 你主动问 AI 小助手时（只发送系统内检索结果）。不配置大模型 Key 则完全不会外呼
- 仓库内演示用的 `input/` 名单全部是**虚构数据**，不含真实客户
